# 票拼拼 · 广告位与配置方案（v1.0 · 2026-09-27）

## 一、设计（用户拍板 C7/C8/C9）
- 左栏「报销金额统计」块删除，原位置放 **AdSense 响应式广告位**（宽度守 Google Ads 规范随容器自适应，高度不限）。
- **无后台**：远端配置文件 `ads-config.js` 控制，纯静态。

## 二、配置文件规范（站点根目录自托管）
```js
// /ads-config.js —— 改这一处，刷新即生效
const ADS_CONFIG = {
  enableAds: false,                       // 总开关（上线初期 false，过审后 true）
  adClient: "ca-pub-XXXXXXXXXXXXXXXX",   // 待填：AdSense 主账号 pub-id（运营维护台账）
  adSlot: "",                             // 待填：本站广告单元 ID
  adFormat: "auto",                       // auto | fluid | rectangle ...
  debug: false                            // true 时占位区显示诊断信息
};
```
**为什么自托管在本站域名而不是第三方域名**（对"AI 朋友方案"的唯一修正）：
1. AdSense 政策明确不建议由第三方代码控制广告投放，被扫到有关号风险——咱们是统一账号多站，全账号经不起一次连坐。
2. 第三方域名一挂，所有站广告同时消失；本站根目录文件+CDN 缓存可控，故障域最小。
3. 效果完全一样：改一个 js 文件全站生效（本站文件 rsync 三端同步即等于"全站"）。

## 三、加载逻辑（core/ads.js）
1. `<script src="/ads-config.js">` 同步先载配置。
2. `enableAds===true && adClient 非占位` → 动态注入 `adsbygoogle.js?client=ca-pub-...`（带 crossorigin）→ 渲染 `<ins class="adsbygoogle" data-ad-client data-ad-slot data-ad-format="auto" data-full-width-responsive="true">` → push。
3. 否则 → 渲染占位卡：默认直接不渲染（DOM 不留空洞）；如版式需要，可渲染 `display:none` 的骨架。debug=true 时显示灰条"广告位（未启用）"。
4. 广告加载失败（onerror/超时 5s）→ 收起容器，页面布局不跳（预留 min-height 仅在已出广告后保持）。
