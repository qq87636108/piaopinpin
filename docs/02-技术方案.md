# 票拼拼 · 技术方案（v1.2 · 2026-09-27，三期裁剪+竞品吸收后）

## 0. 白话总览
一个"不用装任何东西、打开网页就能用"的发票拼版器。所有发票文件只在用户自己电脑的浏览器里处理，不上传服务器。网站本身是纯静态页面（没有账号、没有数据库），托管极轻。

```
浏览器
├── PC 页面  /          （主战场：上传→拼版→打印/导出）
├── 手机页面 /m/         （独立重设计：查看/轻整理/引导去电脑打印）
└── 共享内核 core/       （解析器们 + 排版引擎 + 广告位 —— 一套代码两端用；无任何金额功能 C10）
```

## 1. 技术选型（含"为什么拒"）
| 层 | 选型 | 理由 / 拒备选 |
|---|---|---|
| 框架 | **原生 ES Modules + 无构建**（Tailwind CDN→本地 vendor、Alpine 视需要） | 拒 React/Vue+Vite：单页工具无状态复杂度，无构建=改一处刷一遍的迭代速度，且静态部署零依赖。拒继续"一个 500 行 HTML"：需求书 §7 要求模块化 |
| PDF 渲染 | pdf.js 3.11.x（**自托管 vendor**） | 原型已用同版。拒公共 CDN 直链：国内访问 jsdelivr/cdnjs 不稳，且站要用 AdSense 类质量信号 |
| PDF 文本提取 | pdf.js getTextContent + 正则 | 仅提取发票号/日期（列表信息+排序用）；失败不阻塞。C10 后金额不做提取展示 |
| OFD 渲染 | **策略位① @sharp9/ofdjs（首选，ESM 原生、新、支持印章）② ofd.js（备选）**，失败降级"提示另传该发票截图" | 实测依据：ofd.js 公开 issue 有 Vue3 不兼容/整页空白/电子签章不显示/Template not found 等记录（掘金踩坑帖+GitHub issues）；@sharp9/ofdjs 的 README 明说 AbbreviatedData 路径只画矩形、JBIG2/TIFF/BMP 不支持 → **必须拿真票做 spike 实测后再定**，解析层按可换引擎设计 |
| XML | 原生 DOMParser + 字段映射表 | 零依赖。字段名对齐数电票标准（InvoiceNumber/IssueDate/TaxInclusiveTotalAmount…，参考 fapiao-print `<EInvoice>` 实践，见 wiki [[case-fapiao-print]]） |
| 拖拽 | Sortable.js（vendor） | 原型已用 |
| ZIP | JSZip（vendor） | OFD 本质 ZIP |
| 导出 PDF | **pdf-lib**（vendor）：把每张已渲染裁边的发票图按拼版坐标置入 210×297mm 页面 | 拒 html2canvas+jsPDF 快照式：pdf-lib 坐标精确、天然 A4、无缩放玄学；与预览共用同一份"页面坐标表" |
| 打印 | window.print() + @page A4 margin:0 | 需求书 §5.6；导出 PDF 为主推通道 |
| 存储 | IndexedDB（缩略图缓存，刷新不丢）+ localStorage（设置） | 原图不持久化（隐私+容量） |

## 4. 关键机制
- **三端一致**：预览、打印、导出 PDF 全部吃 `layout.js` 输出的同一份坐标表（单位 mm），杜绝"预览和打印不一样"（R4）。
- **智能裁边**（R1）：渲染→像素扫描找非白包围盒→外扩 4mm→裁切。图片类发票（本身就是截图）默认不裁。裁边失败静默回退整页。
- **解析队列**：逐文件 async，单文件失败只标该条 error 状态，不阻塞队列（需求书 §5.1）。
- **OFD 元数据"点收"法**（吸收自 fapiao-print 源码，见 wiki [[case-fapiao-print]]）：数电 OFD 包内 `Tags/CustomTag.xml` 以字段名→TextObject ID 明文标注发票号/日期/买卖方等，解析器按 ID 直取文字对象，**不做正则猜测**；无 CustomTag 的老票才回退正则。字体名先清洗（`仿宋_GB2312`→`仿宋`）再匹配系统字体。
- **裁白边参数**（同上来源，量产验证）：白色阈值 ~245、留边默认 3px 可调 0-60、裁切框回写记录。
- **终端分流**：访问 `/` 时 UA/宽度检测，手机引导到 `/m/`（可手动切换）；两端共享 core/。
- **隐私**：无后端上传路径；首页显著位置一句"发票文件不离开你的电脑"。
- **广告位与远端配置**（C8/C9，2026-09-27 二期新增）：
  - 位置：左栏原「报销金额统计」卡片处，`core/ads.js` 渲染 AdSense 响应式 `<ins>`（fluid/max-width 合规，高度不限）。
  - 配置：站点根目录 `ads-config.js`（本站域名自托管，**不挂第三方域名**——AdSense 政策不建议第三方代码控制广告投放，且外链挂了=全站广告陪葬）：`{enableAds, adClient, adSlot, adFormat}`。开关=改这一个文件，重刷即全站生效，无后台无数据库。
  - 加载逻辑：`enableAds===true` 且 adClient 非占位值才注入 `adsbygoogle.js?client=...` 并 push；否则渲染轻量占位卡（如"广告"灰条或直接折叠不留空洞），控制台零报错。
  - 配套：根目录 `ads.txt`；挂载节奏守运营中枢铁律**分档挂站**（本站过审拿钱前不牵连其他站），进度回填 `运营维护/广告运营/AdSense账号.md` 与广告位台账。
- **已删模块**（C7+C10 三期定稿）：showBorder / showSummary 设置与渲染分支、totals 大卡、列表金额输入框、**打印卡片金额角标（Q1 已拍板=删）**；`state.settings` 与 `Invoice.amount` 相应字段移除。全站唯一金额文字来源=票面自带内容（图片/PDF 渲染像素、XML 卡片版式）。

### 4.6 文件生命周期与删除时机（C11）
核心事实：**本站无上传接口，用户文件永远不经过/不落在服务器上**——所谓"上传"只是浏览器把本地文件读进本机内存。服务器磁盘占用恒等于零，不存在服务端清理问题。浏览器侧四道闸：
| 时机 | 动作 |
|---|---|
| 解析完成瞬间 | 原始文件 ArrayBuffer/ObjectURL 立即释放，只保留渲染好的缩略图（压缩后 ~100-300KB/张，原图不留内存驻留，需要重新渲染时从本机文件再读） |
| 用户删单张 / 清空全部 | 对应缩略图从 IndexedDB 即时删除 |
| 关闭标签页/浏览器 | 内存由浏览器自动回收（浏览器机制，无需我们写代码）；IndexedDB 缓存按策略留存：TTL 7 天自动清 + 超 200MB 从最旧清 + footer「立即清除数据」一键全清 |
| 本地缓存开关（设置内） | 关闭时 IndexedDB 一行不写，关页即全部蒸发（给最在意隐私的用户） |
红线：二期若加服务端 OFD 转换兜底 → 必须内存流处理零落盘 + 不写日志文件体，做不到就不上该功能。
