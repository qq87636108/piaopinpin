# 票拼拼 技术文档

## 项目概述

票拼拼是一个纯前端的电子发票拼版打印工具，帮助用户将多张发票拼到 A4 纸上打印，节省纸张。

### 核心理念

- **隐私优先**：所有文件处理在浏览器本地完成，不上传服务器
- **开箱即用**：无需安装，打开网页即可使用
- **多格式支持**：PDF、OFD、XML、图片格式全覆盖

## 核心功能实现

### 1. 文件类型嗅探

`dispatch.js` 使用 **扩展名 + Magic Bytes** 双重判断：

```javascript
// Magic Bytes 识别
if (head[0] === 0x25 && head[1] === 0x50) return 'pdf';     // %PDF
if (head[0] === 0x50 && head[1] === 0x4b) return 'zip';     // PK (OFD)
if (head[0] === 0x89 && head[1] === 0x50) return 'image';   // PNG
```

### 2. PDF 解析

**关键问题**：CID 字体渲染空白

**问题描述**：数电票 PDF 使用 CID 编码的中文 Type0 字体，pdf.js 3.x 渲染时文字为空白。

**解决方案**：升级到 pdf.js 4.10.38，并配置 CMap 文件：

```javascript
const pdf = await pdfjs.getDocument({
  data: buf,
  cMapUrl: 'vendor/pdfjs4/cmaps/',  // Adobe CMap 文件
  cMapPacked: true,
}).promise;
```

**CMap 文件**：169 个 `.bcmap` 文件（Adobe 官方开源），用于字体字形映射。

### 3. OFD 解析

**关键问题**：vendor 库补丁

原库 `@sharp9/ofdjs` 存在多个问题，已修补：

| 问题 | 修复 |
|------|------|
| PhysicalBox 缺失 | 添加 fallback 链：page → template → document |
| DPI 错误 | 批量替换 26 处 `mmtopx()` 调用为 196dpi |
| 字体映射失败 | 实现 FONT_MAP 单字体映射表 |
| JBIG2 二维码黑块 | 从 pdf.js 3.x 提取 JBIG2 解码器 |
| AbbreviatedData 不解析 | 实现 M/L/B/Q/C/S 路径命令解析 |

**CustomTag 元数据提取**：

真票 CustomTag.xml 格式特殊（非法 XML）：
```xml
<:eInvoice xmlns="">
  <ofd:InvoiceCode>014002300111</ofd:InvoiceCode>
</:eInvoice>
```

**解决方案**：正则清洗 + getElementsByTagName('*') + localName 匹配。

`crop.js` 实现基于像素分析的裁边：

### 6. 打印优化

**打印空白页问题**：

原因：`visibility: hidden` 元素仍占位，导致内容被挤到后面。

解决方案：
```css
@media print {
  body > * { display: none !important; }  /* 不占位 */
  #print-area { display: block !important; }
  .print-a4:last-child { page-break-after: auto; }  /* 最后一页不换页 */
}
```

## 已知限制

1. **仅支持首页渲染**：PDF/OFD 只渲染第一页，不支持多页
2. **无金额识别**：不提取发票金额（C10 决策）
3. **无 OCR**：不识别图片中的文字
4. **横版发票**：2 张/页时横版发票会缩小（A4 纸张比例限制）

## 开发指南

### 本地运行

```bash
# 克隆仓库
git clone https://github.com/qq87636108/piaopinpin.git
cd piaopinpin

# 启动开发服务器
node site/dev-server.cjs 3090

# 打开浏览器
open http://localhost:3090
```

### 代码规范

- 文件行数 < 200 行
- 函数行数 < 50 行
- 使用 ES Modules
- 注释解释"为什么"而非"是什么"

### 测试

```bash
# 使用 Playwright 进行 E2E 测试
node tests/e2e.mjs
```
