# 票拼拼 · 需求分析与澄清（v1.0 · 2026-09-27）

> 需求基线 = attachments/发票拼版工具说明书.md + 原型 UI.html + 本文档。冲突处以本文档（更新拍板）为准。

## 一、项目定位（一句话）
**打开就能用、文件不出浏览器的免费电子发票拼版打印站** —— 别人要么传服务器要么收费注册，我们主打本地处理 + 零门槛。

## 二、角色与场景
- 报销上班族（主）；企业财务/行政（次）。
- 主场景：电脑打开网站 → 拖入一堆 PDF/OFD/XML/图片发票 → 排序选每页张数 → 打印或导出 PDF。
- 次场景：手机上打开，查看与简单整理（不做打印主战场）。

## 五、功能模块与优先级（2026-09-27 二期修订后）
- **P0**：多格式上传（PDF/OFD/XML/PNG/JPG，单文件 20MB、单次 100 张）、解析队列与错误隔离、缩略图+智能裁边、列表（删除/拖拽排序）、1/2/3/4 张每页、A4 预览分页、剪切线开关、浏览器打印、导出 PDF、示例数据、空态与异常提示、隐私承诺文案（"文件不离开你的电脑"）。
- **P0-广告**：原「报销金额统计」块位置改为 AdSense 响应式广告位（宽度合规、高度不限）；`ads-config.js` 远端配置（enableAds 总开关/pub-id/slot/format），本站根目录自托管，改一处全站生效；未配置/关闭时该位置显示轻量占位（不留白洞、不报错）。
- **已砍**（二期+三期删除）：~~显示报销贴票引导边框~~、~~底部贴票报销汇总表格~~、~~报销金额统计信息块~~（被广告位替代）、~~金额手填/列表金额输入框~~、~~打印卡片金额角标~~、~~按金额排序~~（C10）。
- **金额边界说明**：发票**票面自带**的金额文字（如 XML 还原卡片版式中的"价税合计"栏）属于发票文件内容本身，照常渲染，不算工具功能——工具自身不提供任何金额录入/计算/排序/统计能力。
- **P1**：XML 解析（字段映射+统一卡片模板）、PDF 元数据提取（发票号/日期，用于排序与列表信息）、按日期/文件名自动排序、本地缓存刷新不丢、横向 A4、页边距/间距调节（原型已有，保留）。
- **P2（二期候选）**：自动张数档、发票查重提示（按发票号码）、多图发票合并、批量重命名导出清单 CSV。
- **P2 素材池（吸收自竞品发票酱交互清单，见 wiki case-fapiao-print）**：版面槽位拖拽换位（边缘=插入/中间=对调）、单票微调（移动/缩放/旋转90°/双击重置）、骨架屏渐进加载、多页发票"逻辑票"聚合、EXIF/PDF 旋转归一、打印状态标记。
- **不做**（需求书 §3.3 沿用）：登录注册、云存储、真伪查验、OCR、财务系统对接、**管理后台**（C9 配置文件方案替代）。

## 六、验收口径
以需求书 §9 + §12 第一轮交付标准为准（剔除已砍模块），追加三条：
- 导出 PDF 打开后每页严格 A4、发票数量与设置一致、无页眉页脚。
- 真实发票样例（用户提供后）：OFD 可渲染、PDF 裁边后打印文字肉眼可读。
- enableAds=false 时页面无任何 AdSense 网络请求且布局无破洞；=true 时广告位宽度随容器自适应不破版。
- 全站搜不到工具自生成的金额元素（输入框/角标/统计数）；打印物上除票面自带内容外无金额文字。

## 七、风险
| 风险 | 对策 |
|---|---|
| OFD 库遇真票渲染异常 | 双库互备（ofd.js / @sharp9/ofdjs），再不行降级"请另传该发票截图" |
| 浏览器打印缩放错乱 | 主推导出 PDF 通道；打印通道保留并写操作指引 |
| 大量图片占内存 | 缩略图统一压缩存 IndexedDB/localStorage，原图仅内存驻留 |
| daogong.cc 主站牵连 | 子域名独立目录独立部署，不共享代码库 |
