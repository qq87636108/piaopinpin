关于票拼拼

是什么

票拼拼是一款纯浏览器端的电子发票拼版打印助手。它能帮你把多张电子发票（PDF、OFD、图片）拼到一张 A4 纸上打印，省纸又整齐。

核心特点

  • 隐私安全：所有文件处理都在你的浏览器里完成，发票不会上传到任何服务器
  • 支持多格式：PDF 发票、OFD 数电票、图片格式均可识别
  • 智能拼版：自动识别发票尺寸，按最优排列拼到 A4 纸上
  • 一键打印：拼好直接打印，支持 1-4 张/页
  • 免费开源：完全免费使用，代码开源在 GitHub

技术实现

票拼拼基于现代 Web 技术构建：

  • PDF 解析：PDF.js（Mozilla 开源）
  • OFD 解析：ofdjs（@sharp9 开源）
  • 前端框架：原生 JavaScript + Tailwind CSS
  • 零后端：纯静态站点，无需服务器
